# Asset specifications

| Asset | Specification |
| --- | --- |
| Brand mark | 1024 × 1024 transparent PNG; maintainable SVG for simple geometry |
| Favicon | Legible at 16/32/48 pixels; ICO, SVG, 180/192/512 PNG |
| Hero | 1920 × 1080 WebP/AVIF; aim below 250 KB; essential subject within central 60% |
| Blog cover | 1600 × 900; aim below 150 KB; central 70% crop-safe |
| Social card | 1200 × 630; aim below 300 KB; separate editable typography and image |
| Product screenshot | Actual running UI at 1440 × 900; remove private identity and credentials |

For each asset record purpose, dimensions, format, compression, alt text, prompt, generation tool/date, source and rights, and original file. Use image generation for personalized artwork when available; do not imply an asset was generated if the tool is unavailable. Mark missing assets as pending. Capture screenshots only after running the product. Audio/video specifications follow enabled product capabilities and must retain originals and generation records.
